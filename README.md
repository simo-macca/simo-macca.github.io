## About the site

- **Bilingual.** English and Italian, detected from the browser and remembered; the CV download follows the chosen language.
- **Light and dark.** Follows the system until a theme is chosen, with no flash on load and a circular reveal when switching.
- **Fluid motion.** Scroll reveals, gliding navigation and filter indicators, animated dialogs and a scroll-progress ring, all turned off when the system asks for reduced motion.
- **Accessible.** Semantic landmarks, skip link, keyboard-friendly dialogs and menus, visible focus and labelled controls.
- **Lightweight.** A single static page on GitHub Pages with no backend; the contact form uses [Web3Forms](https://web3forms.com/) with hCaptcha.
